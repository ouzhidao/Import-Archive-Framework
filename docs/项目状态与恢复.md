# 项目状态与恢复（防失忆机制）

> 目的：上下文压缩/会话重启后，读本文件 + runtime/项目状态.json 即可恢复全部历史，不依赖记忆。

## 一、恢复步骤（会话开始时）

1. 读 `runtime/项目状态.json` —— 当前整理进度总账（已整理票/待整理票/缺件/待办）
2. 读 `CLAUDE.md` —— 铁律/架构/命名/管线
3. 读 `docs/命名规范.md` —— 命名规则
4. 每票缺件明细 → 读 `runtime/tickets/{票ID}_index.json` 的 `completeness` 字段
5. 校验/报警 → 读 `runtime/reports/四票校验汇总.json`

## 二、动态状态（每次更新后要刷新）

| 文件 | 内容 | 何时更新 |
|---|---|---|
| `runtime/项目状态.json` | 已整理/待整理票/缺件/待办 | 每整理完一票 |
| `runtime/tickets/*_index.json` | 每票单据清单/缺件/报警 | 补件或改分类后 |
| `runtime/reports/*.json` | 校验汇总 | 重跑校验后 |

## 三、关键规则（防"改回去"）

- **命名规范**：`{YYYYMMDD}_{吨位}t_{正式票ID}_{类型}_{状态}{版本}_{号码}.pdf`（吨位必带，号码末尾）
- **L4 文件夹**：`{YYYYMM-吨位}t-{正式票ID}`
- **友好标签**：`{供应商缩写}-{YYYYMM}-{吨位}t`
- 详见 `docs/命名规范.md`
