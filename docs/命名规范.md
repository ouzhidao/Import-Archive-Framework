# 命名规范（铁律，防失忆）

> 制定：2026-08-01，用户确认。所有归档文件名必须遵守，代码按此生成。

## 一、L4 业务票文件夹

```
{YYYYMM-吨位}t-{正式票ID}
```
示例：`202602-47.58t-PRG-SUR-LECKER-26A-01`

- `YYYYMM-吨位` = 友好标签的"年月-吨位"（如 202602-47.58t）
- 正式票ID = `{主合同号}-{批次}`（如 PRG-SUR-LECKER-26A-01）
- 供应商缩写前缀不需要（在 L2 目录已体现）

## 二、文件名

```
{YYYYMMDD}_{吨位}t_{正式票ID}_{单据类型}_{状态}_{号码}.ext
```
示例：
- `20260301_47.58t_PRG-SUR-LECKER-26A-01_合同_正本.pdf`（无号码）
- `20260301_47.58t_PRG-SUR-LECKER-26A-01_发票_正本_PRGINV2602-048.pdf`
- `20260301_47.58t_PRG-SUR-LECKER-26A-01_提单_正本_BOS2603QD007.pdf`
- `20260301_47.58t_PRG-SUR-LECKER-26A-01_报关单_清关_正本_带价_425820261000056675.pdf`
- `20260301_47.58t_PRG-SUR-LECKER-26A-01_检疫证明_正本_425820261000056675001.pdf`

### 段位说明
| 段 | 内容 | 备注 |
|---|---|---|
| 日期 | YYYYMMDD | 实际入库/到货日 |
| 吨位 | Nt（如 47.58t） | 票总吨位 |
| 票ID | 正式票ID | 合同号-批次 |
| 单据类型 | 受控词 | config/doc_types.yaml |
| 状态 | 正本/盖章件/副本/草稿/修订件 | 受控词 |
| 号码 | 各单证号 | 发票号/提单号/报关单号/检疫证号，**放末尾** |

### 号码规则（放末尾，方便检索）
- 发票 → 发票号（PRGINV2602-048 / SUL-25-26-1118）
- 提单 → 提单号（BOS2603QD007 / PRO2604QD011）
- 报关单 → 报关单号（18位，莱卡尔主号）
- 检疫证明 → 检疫证号（报关单号+001）
- 无号码的单据（合同/箱单/税单/产地证等）→ 无末尾号码段

### 多版本
- 同类型多份不同内容 → 状态后加 `2`（如 `_正本2_`）
- 内容完全相同 → 去重，只留一份

## 三、友好标签（内部沟通）

```
{供应商缩写}-{YYYYMM}-{吨位}t
```
示例：`PRG-202602-47.58t`、`ULKA-202507-84t`

用于内部交流，不用在文件名/文件夹（L4 已含年月-吨位）。

## 四、报关单（角色区分 + 含价/不含价）

### 4.1 角色：保税入库 / 清关（2026-09-04 立规）

报关单按**监管方式**与**境内收货人**分两种角色，文件名/索引都必须标注：

| 角色 | 含义 | 判据 | 收货人 |
|---|---|---|---|
| **保税入库** | 供应商 → 保税库（货先进保税仓） | 监管方式 **1233**（保税仓库货物） | 保税库（坤煜/辽渔/毅都/天驰…） |
| **清关** | 保税库 → 我方（正式进口清关） | 监管方式 **0110**（一般贸易） | 莱卡尔（连云港）海洋食品 |

> **展示话术（2026-10-15 用户定）**：缺件/清单里我方清关的叫 **`清关报关单`**（必备）；
> 无我方信息的保税入库叫 **`保税报关单`**（非必须、不报警）。
> 注意：**文件名中的角色段仍写 `清关` / `保税入库`**（见 4.3），改的只是缺件展示用词，
> `config/doc_types.yaml` 的 id 保持 `报关单` 不动。

- **一票可能两者都有**（先保税入库、后清关）→ 两份都保留，文件名带各自角色 + 各自报关单号
- 自动识别：读报关单文本 `监管方式(1233/0110)` + `境内收货人(社会信用代码)`（莱卡尔=91320722MA2142JP4R）
- **必备性**：**清关（莱卡尔）正本必备**；保税入库**非必须**（统计/完整性校验只卡清关）
- **统计 Excel 只填「清关」（莱卡尔）报关单号**；保税入库号不填

### 4.1.1 关联检索：清关报关单号 = 检疫证号前 18 位（2026-09-04 验证）

一般贸易（清关）下，**海关检疫证号 = 清关报关单号 + 后缀（通常 `001`）**，前 18 位完全一致。实测：

| 票 | 清关报关单号 | 检疫证号 |
|---|---|---|
| 26A-01 | 425820261000056675 | 425820261000056675**001** |
| 26A-03 | 425820261000094687 | 425820261000094687**001** |
| 26B-01 | 426520261000004882 | 426520261000004882**001** |
| ULKA-254903922 | 425820251000182257 | 425820251000182257**001** |

- 用途：**报关单 ↔ 检疫证 可互相检索/校验**（文件名末尾号码、index 关联）
- **仅适用于清关（0110）**；保税入库（1233）单不适用此规律（其关联的是后续清关单号）
- 校验点：清关票若检疫证号前 18 位 ≠ 清关报关单号 → 报警（见 rules.yaml R7）

### 4.2 含价 / 不含价（2026-09-04 立规）

清关报关单原则上**两份**：
- **带价**：给财务（含 单价/总价/币制/美元）
- **不带价**：给质量备案/第三方审核（删 单价/总价/币制 整列）
- 只有带价原件时 → 程序自动生成不带价版：`scripts/mask_customs_price.py`（跨 rotation、按价格 span 动态边界，兼容多商品多行）

### 4.3 命名

```
{YYYYMMDD}_{吨位}t_{票ID}_报关单_{角色}_{状态}_{带价|不带价}_{报关单号}.pdf
```
示例：
- `20260528_20t_PRG-SUR-LECKER-26B-01_报关单_保税入库_正本_带价_422720261000018459.pdf`
- `20260528_20t_PRG-SUR-LECKER-26B-01_报关单_清关_正本_不带价_426520261000004882.pdf`
- 副本/盖章件同样带角色：`..._报关单_清关_副本_425820261000056675.pdf`
