# 命名规范（铁律，防失忆）

> 制定：2026-08-01，用户确认。所有归档文件名必须遵守，代码按此生成。

## 一、L4 业务票文件夹

```
{YYYYMM-吨位}t-{正式票ID}
```
示例：`202602-47.58t-PRG-SUR-LECKER-26A-01`

- `YYYYMM-吨位` = 友好标签的"年月-吨位"（如 202602-47.58t）
- 正式票ID = `{主合同号}-{批次}`（如 PRG-SUR-LECKER-26A-01）
- 供应商缩写前缀不需要（在 L2 目录已体现）

## 二、文件名

```
{YYYYMMDD}_{吨位}t_{正式票ID}_{单据类型}_{状态}_{号码}.ext
```
示例：
- `20260301_47.58t_PRG-SUR-LECKER-26A-01_合同_正本.pdf`（无号码）
- `20260301_47.58t_PRG-SUR-LECKER-26A-01_发票_正本_PRGINV2602-048.pdf`
- `20260301_47.58t_PRG-SUR-LECKER-26A-01_提单_正本_BOS2603QD007.pdf`
- `20260301_47.58t_PRG-SUR-LECKER-26A-01_报关单_正本_425820261000056675.pdf`
- `20260301_47.58t_PRG-SUR-LECKER-26A-01_检疫证明_正本_425820261000056675001.pdf`

### 段位说明
| 段 | 内容 | 备注 |
|---|---|---|
| 日期 | YYYYMMDD | 实际入库/到货日 |
| 吨位 | Nt（如 47.58t） | 票总吨位 |
| 票ID | 正式票ID | 合同号-批次 |
| 单据类型 | 受控词 | config/doc_types.yaml |
| 状态 | 正本/盖章件/副本/草稿/修订件 | 受控词 |
| 号码 | 各单证号 | 发票号/提单号/报关单号/检疫证号，**放末尾** |

### 号码规则（放末尾，方便检索）
- 发票 → 发票号（PRGINV2602-048 / SUL-25-26-1118）
- 提单 → 提单号（BOS2603QD007 / PRO2604QD011）
- 报关单 → 报关单号（18位，莱卡尔主号）
- 检疫证明 → 检疫证号（报关单号+001）
- 无号码的单据（合同/箱单/税单/产地证等）→ 无末尾号码段

### 多版本
- 同类型多份不同内容 → 状态后加 `2`（如 `_正本2_`）
- 内容完全相同 → 去重，只留一份

## 三、友好标签（内部沟通）

```
{供应商缩写}-{YYYYMM}-{吨位}t
```
示例：`PRG-202602-47.58t`、`ULKA-202507-84t`

用于内部交流，不用在文件名/文件夹（L4 已含年月-吨位）。

## 四、双报关单（莱卡尔 + 坤煜保税）

- 统计 Excel **只填莱卡尔（本公司）报关单号**
- 文件：坤煜报关单保留，用坤煜报关单号命名（末尾）
- 区分：坤煜号 ≠ 莱卡尔号，天然可区分
