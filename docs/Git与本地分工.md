# Git 与本地分工（交接说明）

> 场景：**同一台电脑**上，本项目交给另一个 Agent 接手。
> 因此 **密钥无需隔离**（`.env` 就在本机，接手 Agent 直接读即可）；但 **推 Git 的内容** 与 **只留本地的内容** 必须严格分开 —— 数据层与真实密钥**永不进 Git**。
> 上位规则见 `AGENTS.md`「二、铁律」。

---

## 一、Git 层（可推远端 · 只放"方法与规则"）

| 路径 | 内容 | 为何进 Git |
|---|---|---|
| `AGENTS.md` | 项目宪法（铁律/架构/口径/复核） | 跨机、跨 Agent 复用 |
| `README.md` / `ARCHITECTURE.md` | 说明与架构 | 同上 |
| `CLAUDE.md` | 指针（→ AGENTS.md） | 兼容旧引用 |
| `config/*.yaml` | 业务规则（供应商/单据/路由/规则/路径） | 改规则不改代码 |
| `scripts/*.py` | 管线（OCR/归票/索引/落盘/去价/查看器） | 工具 |
| `docs/*.md` | 命名规范 / 状态与恢复 / 借鉴 / 本文件 | 方法论 |
| `schema/` `templates/` | 预留（当前为空） | 结构占位 |
| `.env.example` | **密钥模板（假值）** | 告诉别人要配哪些变量 |

## 二、本地层（**不进 Git** · 数据 / 密钥 / 真实文件）

| 路径 | 内容 | 说明 |
|---|---|---|
| `.env` | **真实密钥**（百度 OCR A/B/C 账户等） | 本机可用；换电脑需重配。`.gitignore` 已挡 |
| `runtime/**` | `tickets/*_index.json`（真源）、`票总览.html`、`缺件清单.md`、`cache/`、`2026_work/`、`_backup_*/`、`inbox/`、`mapping/` | 运行时数据，动态 |
| `SUP_*/` `00_主档/` | 归档副本与主档 Excel | 业务数据 |
| 红线区 `C:\Users\34009\Desktop\03_合同与订单\进口单证归档\` | **真实单据正本**（只读） | 绝不改/删/移 |
| F 盘 `…\进口原料单证整理\` | 对外成果（HTML/Excel） | 权威发布位置 |
| 原始来源 | 微信 `E:\软件\xwechat_files\…`、`Downloads`、`Desktop\数据整理\杂进口单据整理` | 投递入口 |

## 三、为什么这样分

1. **合规**：真实税号/账号/海关号/单据属敏感数据，出仓即风险 → 只留本机。
2. **可复用**：Git 层是"方法与规则"，换电脑/换 Agent 只拉仓库即可，不夹带业务数据。
3. **`.gitignore` 双重兜底**：既忽略 `runtime/**`、`SUP_*/`，也全局忽略 `*.pdf|png|jpg|zip|rar|docx|xlsx|json` 和 `.env`。

## 四、接手 Agent 上手清单（本机）

1. 读 `AGENTS.md`（宪法）→ `docs/项目状态与恢复.md`（进展/待办）
2. `.env` **已配好**（本机），直接可跑 OCR；无需向你索要密钥
3. 真源 = `runtime/tickets/*_index.json`；缺件 = `runtime/缺件清单.md`
4. 落盘前：**备份 → copy 不移动 → ≤10/批 → 出映射清单等确认**
5. 干活前 `git pull`；改动只在 Git 层提交（`git status` 应只见 docs/config/scripts/*.md）

## 五、换电脑时（例外）

需三样一起搬：① 本仓库（git clone）② `.env`（手动带）③ `runtime/` 与红线区（本地拷贝）。
—— 但那属于"换机"，不是本次"同机交接"，本次 **无需任何迁移**。
